# content-toolkit — 内容采集工具箱（学员版）

把抖音博主的内容变成你的素材库：**逐字稿 + 点赞评论数据**，一个文件夹一个博主，Markdown 格式随便用。

## 它能干嘛

| 你想要 | 它做 | 用时 |
| --- | --- | --- |
| 「把这几条视频的文字扒下来」 | 链接丢进去 → 全文逐字稿 + 数据 | 每条约 1-2 分钟 |
| 「盯住这个博主，更新就帮我存」 | 博主加入监控列表，随时一条命令拉新 | 20 条约 40 分钟（主要是转写） |
| 「把这个博主**全部**历史视频导出」 | 从得到大脑（Get笔记）批量导逐字稿 + 社媒助手拉数据，合并 | 700 篇约 10 分钟 |

## 怎么安装（小白三步）

**你只需要：一台 Mac 或 Windows 电脑 + 装了 Claude Code 或 WorkBuddy（或任何会用 skills 的 AI agent）+ 两个免费账号。**

1. **把这个文件夹整个发给你的 AI**，对它说：
   > 帮我安装这个工具包，按 INSTALL.md 操作
2. AI 会跑自检，然后引导你填两个 key（跟截图走就行）：
   - **阿里云百炼 Key**（语音转文字用）：https://bailian.console.aliyun.com 注册 → 左侧「API-KEY」→ 创建（sk- 开头）。新用户有免费额度
   - **Monid Key**（抖音数据用）：https://app.monid.ai 注册 → Access / API Keys → 创建（monid_live_ 开头）。新号送 $1 额度，够抓几百条
3. 拿一条抖音视频链接试一下：
   > 用 content-toolkit 把这条视频转成逐字稿 https://v.douyin.com/xxxxx/

完成 ✅ 之后的所有用法，直接用大白话跟你的 AI 说就行（它在 SKILL.md 里都学了）。

## 常见问题

- **我是纯小白，装不上怎么办？** 把报错截图发给你的 AI，让它按 INSTALL.md 里的排错表处理；实在不行把 `doctor.py` 的输出发给老师。
- **哪些环节要人工？** 一次性登录得到大脑（扫码）；社媒助手插件登录；第一次导出时 AI 会问你一次「素材放哪个文件夹」（直接回车就用下载文件夹）。之后全自动。
- **Windows 能用吗？** 能。两条流水线都支持：脚本纯 Python 标准库，社媒助手自动化会自动找到并拉起 Windows 上的 Chrome。差异只在安装路径，你的 AI 看 INSTALL.md 就知道。
- **我是 WorkBuddy 用户行吗？** 行，装到 `~/.workbuddy/skills/` 即可，用法完全一样。
- **会不会封号？** 工具全部走官方/付费接口或有节奏控制，不做高频爬取。请仅用于个人学习研究，遵守平台条款。
